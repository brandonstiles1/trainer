# Plan 1 — Foundation & Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a deployable Next.js app with Google OAuth, the full database schema + RLS, and an empty 4-tab shell. At the end, a user can sign in with Google and see their `profiles` row auto-created in the DB.

**Architecture:** Next.js 15 (App Router) → Supabase (Postgres + Auth + Storage) → Drizzle ORM for typed queries and migrations. Google OAuth handled entirely by Supabase Auth. Server Components read via `@supabase/ssr`; middleware gates protected routes. The full schema (all 7 tables from the spec) is committed in Plan 1 so future plans only add features, not migrations.

**Tech Stack:** Next.js 15 · React 19 · TypeScript · Tailwind CSS · shadcn/ui · Supabase JS · Drizzle ORM + drizzle-kit · Vitest · Zod

## Prerequisites (manual, one-time)

Before executing any tasks, complete these steps. Do them in order.

1. **Create Supabase project** at https://supabase.com → "New Project." Pick any region close to you. Save the database password.
2. **Get credentials** from Supabase Dashboard → Project Settings → API:
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` key → `SUPABASE_SERVICE_ROLE_KEY`
3. **Get DB connection string** from Dashboard → Project Settings → Database → "Connection string" → URI mode → Transaction pooler. Replace `[YOUR-PASSWORD]` with the db password from step 1. Save as `DATABASE_URL`.
4. **Set up Google OAuth**:
   - Go to https://console.cloud.google.com → new project → "OAuth consent screen" → External → fill minimal info
   - "Credentials" → "Create credentials" → "OAuth client ID" → Web application
   - Authorized redirect URI: `https://<project-ref>.supabase.co/auth/v1/callback` (find `<project-ref>` in Supabase URL)
   - Copy client ID + client secret
   - Back in Supabase: Dashboard → Authentication → Providers → Google → Enable, paste ID + secret, Save
5. **Create `.env.local`** in the repo root with all the above values (template will be committed as `.env.example` in Task 22).

**Why this layout:**
- `lib/supabase/` has three variants because `@supabase/ssr` needs different cookie-handling setups for browser vs server vs middleware contexts.
- Full Drizzle schema in one `schema.ts` file (all 7 tables) — spec is stable so splitting by domain is premature.
- Pure-SQL RLS policies live in `supabase/policies.sql` because Drizzle doesn't express CREATE POLICY / CREATE TRIGGER cleanly. Applied via a documented one-time command.
- Server actions in `settings/actions.ts` colocated with the page that uses them.

  return createServerClient(

        getAll() {

        setAll(cookiesToSet) {
          try {

              cookieStore.set(name, value, options),

            // Called from a Server Component — ignore. Middleware refreshes the session.
          }

      },
    },
  );

- [ ] **Step 3: Write `lib/supabase/middleware.ts`**

```ts
import { createServerClient } from "@supabase/ssr";
import { NextResponse, type NextRequest } from "next/server";
import { publicEnv } from "@/lib/env";

export async function updateSession(request: NextRequest) {
  let supabaseResponse = NextResponse.next({ request });

  const supabase = createServerClient(
    publicEnv.NEXT_PUBLIC_SUPABASE_URL,
    publicEnv.NEXT_PUBLIC_SUPABASE_ANON_KEY,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll();
        },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value }) =>
            request.cookies.set(name, value),
          );
          supabaseResponse = NextResponse.next({ request });
          cookiesToSet.forEach(({ name, value, options }) =>
            supabaseResponse.cookies.set(name, value, options),
          );
        },
      },
    },
  );

  const { data: { user } } = await supabase.auth.getUser();

  const publicPaths = ["/login", "/auth/callback"];
  const isPublic = publicPaths.some((p) => request.nextUrl.pathname.startsWith(p));

  if (!user && !isPublic) {
    const url = request.nextUrl.clone();
    url.pathname = "/login";
    return NextResponse.redirect(url);
  }

  if (user && request.nextUrl.pathname === "/login") {
    const url = request.nextUrl.clone();
    url.pathname = "/today";
    return NextResponse.redirect(url);
  }

  return supabaseResponse;
}
```

## Task 8: RLS policies + auto-profile trigger

**Files:**
- Create: `supabase/policies.sql`

- [ ] **Step 1: Write `supabase/policies.sql`**

```sql
-- ============================================
-- Row Level Security — each user sees only their own rows.
-- Apply once after running Drizzle migrations.
-- Run with: psql "$DATABASE_URL" -f supabase/policies.sql
-- ============================================

alter table public.profiles        enable row level security;
alter table public.goals           enable row level security;
alter table public.plans           enable row level security;
alter table public.lift_estimates  enable row level security;
alter table public.workouts        enable row level security;
alter table public.workout_sets    enable row level security;
alter table public.photos          enable row level security;

-- ---------- profiles ----------
create policy "profiles: user reads own"
  on public.profiles for select using (user_id = auth.uid());
create policy "profiles: user updates own"
  on public.profiles for update using (user_id = auth.uid());

-- ---------- goals ----------
create policy "goals: user owns"
  on public.goals for all
  using (user_id = auth.uid())
  with check (user_id = auth.uid());

-- ---------- plans ----------
create policy "plans: user owns"
  on public.plans for all
  using (user_id = auth.uid())
  with check (user_id = auth.uid());

-- ---------- lift_estimates ----------
create policy "lift_estimates: user owns"
  on public.lift_estimates for all
  using (user_id = auth.uid())
  with check (user_id = auth.uid());

-- ---------- workouts ----------
create policy "workouts: user owns"
  on public.workouts for all
  using (user_id = auth.uid())
  with check (user_id = auth.uid());

-- ---------- workout_sets ----------
-- No user_id column; access via parent workout.
create policy "workout_sets: user owns via workout"
  on public.workout_sets for all
  using (
    exists (
      select 1 from public.workouts w
      where w.id = workout_sets.workout_id
        and w.user_id = auth.uid()
    )
  )
  with check (
    exists (
      select 1 from public.workouts w
      where w.id = workout_sets.workout_id
        and w.user_id = auth.uid()
    )
  );

-- ---------- photos ----------
create policy "photos: user owns"
  on public.photos for all
  using (user_id = auth.uid())
  with check (user_id = auth.uid());

-- ============================================
-- Auto-create profile row on auth.users insert.
-- ============================================
create or replace function public.handle_new_user()
returns trigger
language plpgsql
security definer
set search_path = public
as $$
begin
  insert into public.profiles (user_id)
  values (new.id)
  on conflict (user_id) do nothing;
  return new;
end;
$$;

drop trigger if exists on_auth_user_created on auth.users;
create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();
```

## Task 11: OAuth callback route

**Files:**
- Create: `app/auth/callback/route.ts`

- [ ] **Step 1: Write `app/auth/callback/route.ts`**

```ts
import { NextResponse } from "next/server";
import { createClient } from "@/lib/supabase/server";

export async function GET(request: Request) {
  const { searchParams, origin } = new URL(request.url);
  const code = searchParams.get("code");
  const next = searchParams.get("next") ?? "/today";

  if (code) {
    const supabase = await createClient();
    const { error } = await supabase.auth.exchangeCodeForSession(code);
    if (!error) {
      return NextResponse.redirect(`${origin}${next}`);
    }
    console.error("OAuth callback error:", error);
  }

  return NextResponse.redirect(`${origin}/login?error=oauth_failed`);
}
```
